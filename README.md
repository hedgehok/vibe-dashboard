# Vibe Dashboard

Интерактивный веб-дашборд для отображения подробной информации о пользователе и его устройстве.

## Возможности

- Информация о браузере (версия, язык, cookies)
- Системная информация (ОС, платформа, память)
- Сетевые параметры (тип подключения, скорость)
- Геолокация (часовой пояс, язык)
- Метрики производительности
- Поддерживаемые функции
- Маркетинговая информация
  - Категоризация устройства и браузера
  - Метрики вовлеченности
  - Технические возможности
  - Предпочтения пользователя
  - Сегментация
  - Данные о сессии
  - Поведенческие метрики

## Технологии

- React
- TypeScript
- Material-UI
- Chart.js
- UA-Parser-JS

## Установка

```bash
# Клонировать репозиторий
git clone https://github.com/hedgehok/vibe-dashboard.git

# Перейти в директорию проекта
cd vibe-dashboard

# Установить зависимости
npm install

# Запустить проект
npm start
```

## Деплой

Для публикации на GitHub Pages используйте:

```bash
npm run deploy
```
